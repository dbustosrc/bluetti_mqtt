# Bluetti to MQTT

Connect Bluetti power stations to Home Assistant over Bluetooth and MQTT. The app runs the bridge inside Home Assistant on AMD64 and ARM64. With MQTT discovery enabled, Home Assistant creates the available sensors and controls automatically.

Supported models include AC60, AC70, AC180, AC200L, AC200M, AC300, AC500, EB3A, EP500, EP500P, and EP600. This fork expands AC60 support with three DC inputs, additional battery and AC readings, and control readback.

Open the **Documentation** tab for setup and configuration. See the [project README](https://github.com/dbustosrc/bluetti_mqtt/blob/main/README.rst) for CLI usage, model details, and credits.
